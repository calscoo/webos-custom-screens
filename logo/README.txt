Put one picture in this folder for the power-off screen, then run ./install.sh

A logo on a transparent background (PNG) looks best. The TV shows it centered on black,
up to 640x320 on its 1920x1080 screen, about the size of LG's logo.
While this folder is empty, ./install.sh uses the sample logo in samples/logo.png.
To keep LG's logo, run ./install.sh --no-logo
